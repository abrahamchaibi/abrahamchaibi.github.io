# Abraham Chaibi

A static personal website.

## Preview

From this folder, run:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://localhost:8000. You can also open `index.html` directly, although YouTube playback should be tested over HTTP.

## Edit

- Content, links, and video titles: `index.html`.
- Colors, type, and spacing: `style.css`.
- The locally hosted Crimson Pro font is distributed under the SIL Open Font License in `assets/fonts/OFL.txt`.
